# 🥤 Coca-Cola Sales Dashboard — Power BI

Interactive sales performance dashboard built in Power BI,
covering beverage brand analysis across U.S. cities and regions.

## 📊 Visuals & Features

- **Sales Table** — Total Sales, Units Sold, Price per Unit,
  Operating Profit and Margin by brand and city
- **Key Influencers** — Factors driving Operating Profit
  (Beverage Brand, Region, Retailer)
- **Geospatial Map** — Sales performance across U.S. states
- **Date Filter** — Adjustable time range slicer

## 📌 KPIs Tracked

`Total Sales` · `Units Sold` · `Price per Unit`
`Operating Profit` · `Operating Margin`

## 🛠️ Stack

`Power BI` `DAX` `Power Query`

## 📂 Dataset

Coca-Cola sales data including Beverage Brand, City, Region,
Retailer, Invoice Date, and financial metrics.
